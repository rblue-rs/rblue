# rblue example 调试工作台原型

桌面直接用浏览器打开 `index.html`；桌面评审手机版可打开 `mobile.html`，支持 375 / 390 / 430px 实时切换。无需构建、联网或安装前端依赖。

这是一份基于 **rblue Flutter example** 的功能设计与 HTML 原型，全部 BLE 数据和操作均为模拟；没有接入 Flutter、C ABI 或真实蓝牙。页面默认展示一个已连接的演示设备，便于直接评审 GATT 操作。

## 功能安排

| 优先级 | 模块 | 设计的调试功能 | 验证目标 |
|---|---|---|---|
| P0 | 设备扫描 | 扫描启停、标识去重、RSSI 排序、名称/标识搜索、可连接/强信号筛选 | 能发现目标设备，区分仅广播设备；iOS 展示平台 UUID |
| P0 | 连接与 GATT | 连接/断开、广播原始数据、服务重发现、服务/特征实例定位、连接信息 | 断连后清理旧实例；切换设备时保留清晰的操作上下文 |
| P0 | 特征操作 | HEX/UTF-8、字节数、读写权限门禁、两种写入模式、长度校验 | 无效 HEX 和空内容可解释；超长写入显示 InvalidLength，既不截断也不自动分包 |
| P0 | 通知数据流 | 订阅/取消、包计数、时间/设备/特征/HEX/UTF-8、暂停显示、清空 | 暂停显示时仍接收；断连取消订阅；缓冲有上限 |
| P0 | 环境与能力 | 平台、适配器、授权、后端、能力边界 | 减少因环境和平台能力差异导致的误判 |
| P0 | 会话日志 | 时间、级别、操作、设备与结果，按级别筛选，JSON 导出 | 将环境与事件一起提供给问题复现者 |
| P1 | 重连实验 | 意外断连、超时、Android 133 模拟；1s/2s 退避、服务重发现、可选恢复原订阅 | 看清每一次重试及恢复动作；仅恢复故障前存在的订阅 |
| P1 | 链路查询 | RSSI、MTU、最大写长、平台说明 | 查询与设置能力分开表达，结果标明来源 |

设备调试页将设备列表与 GATT 操作并排，减少往返页面；数据流和日志独立成页，避免大量数据挤占操作区。手机宽度（≤680px）采用独立的任务层级：

- 底部固定五个入口：设备、数据流、重连、环境、日志；预留底部安全区。
- 首页只展示设备列表、扫描操作和一条连接摘要，避免四个桌面指标占用首屏。
- 点击设备进入详情，提供显式返回列表；切换底部模块后回到设备页展示列表，保留选中的设备与当前连接。
- 详情内展示服务、特征及操作；编码与写入方式纵向排列，输入字号为 16px，主要操作触控区至少 44px。
- 通知表格将设备/特征来源合并到首列，日志将时间合并到事件列，保留上下文并减少横向滚动。
- 实时控制台与完整日志合并为底部的“日志”入口；临时提示显示在底部导航上方。
- 375 / 390 / 430px 预览器直接加载同一个 HTML，不复制交互逻辑。

真实手机上的软键盘、系统安全区及原生手势仍需在 Flutter 实现阶段验证。

## 与现有实现的关系

依据 `lib/src/pages/`、`rblue_flutter/lib/src/client.dart` 和 `KNOWN-GAPS.md`：

- 当前 example 已有扫描、连接、服务发现、读写、通知、宿主层重连与平台说明；本设计整合这些操作，并补充筛选、编码选择、日志导出等调试入口。
- 当前 C ABI 有 RSSI、MTU 查询、capabilities 和 max_write_len。原型固定 MTU 为 247、最大写长为 244，这只是演示预设；真实应用须按设备与写入模式读取实际限制。
- 主动 MTU 协商、配对、描述符读写尚未暴露；Rust supervisor/queue 尚未通过 C ABI 导出。本期不设计可执行入口。
- GATT Server、广播发射、OTA、批量压测不在此次范围。
- Demo Service FFF0、三个特征与设备身份均为本原型构造，不宣称来自现有 mock 后端或真实设备。
- 133 仅为注入场景。真实连接失败路径未必保留原始码，不应从普通 NotConnected 反推 133。
- 通知只统计原型接收数，不宣称提供底层丢包率。日志最多保留 300 条、通知包最多 200 条；导出也受此范围限制。
- 切换模拟平台会清理连接；刷新页面清空当前会话，导出操作下载 JSON 文件。

## 验证

`smoke.cjs` 使用外部已安装的 Playwright，不向项目新增依赖：

```sh
PLAYWRIGHT_MODULE=/absolute/path/to/node_modules/playwright node smoke.cjs
```

覆盖搜索、扫描、超长与无效 HEX 写入、中文 UTF-8 字节数、特征权限、通知暂停、重连恢复、JSON 下载、平台能力门禁，以及 320/375/390/430/768/844/1024/1440px 的各页面溢出检查。新增手机详情进入/返回、中文写入、底部导航触控区和预览宽度切换验证。测试生成桌面、手机列表、详情、数据流和预览板截图以供视觉检查。

原型通过不代表真实蓝牙或原生应用行为验收通过。
