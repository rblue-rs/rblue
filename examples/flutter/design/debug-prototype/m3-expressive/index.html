Example 调试功能规划
基于当前 rblue Flutter example 设计，桌面采用双栏工作台，移动端按同一任务顺序纵向展示。
P0 / 基础链路与问题定位
  • 适配器与权限状态、真实 / Mock 后端标识、能力门禁。
  • 扫描启停、名称与标识搜索、可连接与 RSSI 筛选、标识去重。
  • 连接 / 断开、广播详情、带实例标识的 GATT 服务树。
  • HEX / UTF-8 读写、写入方式、字节数与长度校验、统一 InvalidLength 提示。
  • 通知订阅 / 取消、数据包查看、接收计数、暂停显示。
  • 带时间与上下文的错误日志、会话 JSON 导出。
P1 / 可靠性验证
  • 断连 / 超时 / 133 故障模拟、退避时间线、服务重发现与订阅恢复。
  • RSSI / MTU / 最大写长查询，平台能力差异展示。
待底层能力补齐后再设计操作入口
主动 MTU 协商、配对、描述符读写与 Rust supervisor / queue 的 C ABI 导出。压力测试和底层丢包统计需要独立的可测量方案，本原型不提供虚构指标。
