# rblue

**Name-reservation release** of the `rblue` crate on crates.io.

rblue = Rust + Blue(tooth) — cross-platform async Bluetooth Low Energy for
Windows, macOS, Linux, iOS, Android, Web Bluetooth, and HarmonyOS.

Nothing in `0.0.x` is usable yet. See the
[repository](https://github.com/charles0122/rblue) for status and design.
